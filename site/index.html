1Selected work

  1. Agent Floor

    private repoElectronReactNode.js

    A desktop control room for a team of AI agents. It runs Claude Code, Codex and Grok agents as command-line sessions I can reach from my phone; an agent can also get its own Docker Linux desktop.

    Over 1,300 automated tests. Every release ships with a rollback.

    Read the case study: Agent Floor

  2. mesh-memory

    Oct 2026TypeScriptSQLite FTS5MCP

    An MCP server that gives agents across my machines one keyword index over shared notes, with token auth and gitleaks redaction before indexing.

    Recall test set: 9 of 10 answers in the top 5 at build. Fixes from an independent security review.

    Read the case study: mesh-memory

  3. ClipShot

    public, MITPythonGTK4

    An open-source screenshot tool for Linux: Wayland-first capture, OCR, an annotation editor, a clipboard daemon run as a systemd user service, and a distro-aware installer.

    Core modules are tested headless with pytest. The code is on GitHub.

    See the code on GitHub: ClipShot

  4. Cost-capped agent team

    test runsclaude -pprompt caching

    Headless Claude workers that share one cached prompt, with a model and effort level per task, hard spending caps and a cost ledger.

    94% cache hit on a test relaunch. In an escape test, worker commands could not write outside their folder, read SSH keys or reach the network.

All work, including the research method and earlier experiments
