What it does

My agents keep their notes, lessons and project records as Markdown files. mesh-memory indexes those files and lets any connected agent search and read them through three MCP tools: memory_search, memory_read and memory_sources.

How it fits together

Decisions

  • Markdown stays the truth. The index sits beside the notes; it does not replace them.
  • Keyword search first. One SQLite FTS5 index with BM25 ranking, served over MCP.
  • Redact before storing. Secrets that gitleaks finds are replaced before anything reaches the index.
  • A token on every route. Only the health check is open.

Results

  • A 10-question recall test set: 9 of 10 answers in the top 5 results at build.
  • An independent security review on the day it was built; its fixes are in the code.

Limits

  • It is keyword search, not semantic search.
  • Not every agent is connected. Some are left out on purpose, one gets only the command-line client, and each machine is set up by hand.
  • It was written with Claude Code in a single session. The recall test and the security review are how I checked it.
